# Nutriva

Native iOS nutrition companion built with SwiftUI and Xcode.

## Goals
- Daily meal logging, calories, protein and weight trends
- Shift-aware meal plans
- Online AI-assisted text and photo meal interpretation, with user confirmation
- Multi-user-ready data isolation and secure server-side AI API

## Delivery milestones
1. SwiftUI iOS shell, navigation and local demo data
2. Auth and per-user food logs
3. Online AI food interpretation with verified nutrition estimates
4. Shift-aware meal planning and weight trends
5. Personal iPhone beta testing

## Security
Never commit API keys, secrets, or personal health records. Keep AI provider credentials on the server. Enforce per-user authorization and database row-level security.

## Status
Planning / repository initialization. No iOS build or backend deployment verified yet.
